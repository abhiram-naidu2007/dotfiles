i3 SURVIVAL SHEET   (Super = the Windows key)       file: ~/dotfiles/docs/i3-survival.txt
EVERY key and command, searchable:  Super + /   (the launcher's Keys tab; type desktop, launcher, files,
bar, terminal, nvim, zathura or browser to see one part).  It is built from the "## text" lines in the i3 config
and from ~/dotfiles/rice/.local/share/rice/keys.tsv: add a line there and it shows up.

LOST / STUCK?
  Super+Esc ........ power menu (lock, logout, suspend, reboot, shutdown)
  Ctrl+Alt+F3 ...... text console: log in, run  startxfce4  or reboot
  Log out, choose "Xfce Session" at login = old desktop, untouched
  Esc / Enter ...... leave resize mode (after Super+R)
  Alt+F4 ........... close a window if Super+Q fails

OPEN THINGS
  Super+Enter ...... terminal (fish)        also Ctrl+Alt+T
  Super+A / Space .. launcher, Apps tab (type name, Enter). Click the Poke Ball on the bar for the same.
  Super+O .......... find ANY file on the disk as you type      Super+D ... PDFs, newest first (opens zathura)
  Super+= .......... calculator (qalc): sqrt(2), 20!, solve(x^2 = 2), 5 km to mi. Enter copies the result
  Super+U .......... web: bookmarks of every browser profile; no match = open the address or search for it
  Super+Tab ........ window switcher
        in the launcher: Ctrl+Tab next tab (keeps your text) | =2^10 calculates | ?words searches the web
        on a file: Enter open | Shift+Enter show in folder | Ctrl+Y copy path | Ctrl+T terminal there | Ctrl+O edit
        filters: pdf: doc: img: vid: audio: code: dir: file: ext:rs    folders: notes/   docs/intro
  Super+B .......... Thorium (last profile)   Super+Shift+B ... choose Thorium profile (3 accounts)
  Super+E .......... file manager
  Super+G .......... lock screen
  Print ............ screenshot of screen     Super+Shift+S ... drag an area or click a window (~/Pictures + clipboard)
  Super+Ctrl+S ..... capture menu: area, window, screen, record area, record screen, record with sound
  Super+Ctrl+R ..... screen recording: select an area to start, press again to stop (~/Videos; red REC pill on the bar)
                     For long or produced recordings (webcam, several sources, streaming): OBS Studio, in the launcher.
  Super+C .......... clipboard history       Super+` ......... drop-down terminal (same key hides it)
  Super+I .......... quick settings (sound, network, bluetooth, display, mood and wallpaper)
  Super+Shift+W .... showcase layout on workspace 3 (press again to close)

LOOK (one palette for every program; details: rice help)
  Super+T .......... mood: night -> day -> paper (cream and ink for reading; every window goes through an e-ink shader)
  Super+Shift+T .... mood and wallpaper menu
  Super+Ctrl+W ..... wallpaper picker: live and normal wallpapers; the colours are read from the picture
  Super+Ctrl+A ..... draw a new mathematical wallpaper (attractor, harmonograph, Julia set, prime spiral, rose)
  Super+Ctrl+D ..... live wallpapers move / hold still. They move only while the workspace is empty and never on battery.
                     Super+Ctrl+N = next live wallpaper: the Spirited Away train, Howl's castle, the temple, the
                     mathematical ones. Pick live or normal wallpapers by sight in Super+Ctrl+W.
  Bar: Poke Ball = launcher, globe = web. Moon/sun/book = mood (click: next, right click: menu). HP bar = battery.
                     Click the date = calendar. Wheel over the speaker = volume.
  Music pill (appears when anything plays, browser tabs too): click title = play/pause,
                     arrows = previous/next, wheel = seek 5 s, right click title = hide the title.
  Pictures live in ~/dotfiles/wallpaper and ~/Pictures/wallpapers.   Terminal: rice wall next | rice art julia 42

PDF (zathura; the page takes the palette's colours).  F1 inside zathura lists every key.
  j k h l scroll | d u half page | J K page | gg G first/last | 12G page 12 | / search, n N next/previous
  a fit page (how it opens) | s fit width | + - zoom | D two pages | i palette colours <-> the document's own
  Alt+1 desktop palette | Alt+2 paper (cream and ink) | Alt+3 night (black) | Alt+4 the document's own colours
  Tab outline | f follow a link | F11 fullscreen | r reload | Ctrl+N status bar | q quit
  It remembers the page of every file and reloads when the file changes (LaTeX, Typst).

DISPLAYS (external monitor)
  Super+P .......... display menu: mirror / extend / monitor only / laptop only
  Super+Ctrl+M ..... mirror        Super+Ctrl+E ..... extend (monitor to the right)
  Super+Ctrl+O ..... monitor only  Super+Ctrl+L ..... laptop only
  At login the laptop screen is mirrored automatically when a monitor is plugged in.

WINDOWS (they tile: never overlap, no title bar, no X button)
  Super+Q .......... CLOSE focused window
  Super+arrows or h j k l ........ move focus (h=left j=down k=up l=right)
  Super+Shift+arrows / h j k l ... move the window
  Super+F .......... fullscreen on/off
  Super+Shift+Space  float on/off (floating window: hold Super + drag mouse to move it)
  Super+R .......... resize mode: h j k l or arrows, then Esc
  Super+W .......... tabbed layout    Super+S .... split layout
  Super+V / Super+Shift+V .. choose where the NEXT window opens (below / beside)

SAME WORKSPACE, SEVERAL WINDOWS (e.g. Thorium + Firefox side by side)
  Super+Left/Right ... jump focus to the window on that side (Up/Down for stacked ones)
  Super+Tab .......... pick any window by name from a list (works across workspaces)
  Super+W ............ tabbed layout: all windows as tabs in one frame; then Super+Left/Right switches tab
  Super+S ............ back to split layout
  Super+Shift+Left/Right .. swap the focused window with its neighbour
  Super+Q ............ close ONLY the focused window (the one with the coloured border)
  Closing the last window of a workspace just leaves it empty.

MISTAKES / UNDO
  Wrong layout .......... Super+S (split) or Super+W (tabbed); Super+Shift+Space toggles float
  Window on wrong workspace ... Super+Shift+<number> sends it to the right one
  Closed something by mistake ... reopen the app; Thorium: Ctrl+Shift+T restores a tab/window
  Bad config edit ....... i3 keeps running the OLD config if the new one has errors; check with
                          i3 -C -c ~/.config/i3/config   then  cd ~/dotfiles && git checkout -- <file>

WORKSPACES (separate screens; you do not "create" them, just go to one)
  Super+1 ... Super+0 .... go to workspace 1..10 (empty ones appear in the bar when you visit)
  Super+Shift+1..0 ....... send the focused window to that workspace (you stay here)
  Super+Ctrl+Right/Left .. next / previous workspace
  Tip: browser on 2, terminal on 1, files on 3. Click a number in the bar to jump too.

i3 ITSELF
  Super+Shift+C ... reload config       Super+Shift+R ... restart i3 (keeps windows)
  Super+Shift+E ... exit menu (asks before logout)
  Check config before reload:  i3 -C -c ~/.config/i3/config

MUSIC (limusic; not autostarted, launches on first press)
  Super+M .......... open / show / hide limusic (scratchpad, floats over any workspace)
  Super+F8 ......... previous track     Super+F9 ... play/pause     Super+F10 ... next track
  Polybar music: left click play/pause, right click next, middle click show/hide
  Quit to free RAM (~660 MB):  pkill -x limusic-app
  Terminal:  playerctl -p limusic play-pause|next|previous|status
             playerctl -p limusic position 30   volume 0.5   shuffle Toggle
  In app: Ctrl+K search, Ctrl+H all shortcuts, Ctrl+wheel zoom

MEDIA KEYS: volume, mute, brightness, play/next/prev work from the keyboard.
